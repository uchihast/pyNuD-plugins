Irregular Molecule Detection Manual

This plugin finds molecules without a fixed shape in HS-AFM height images and measures their area, volume, height and strand length. It does not assume a circle, ellipse or any other shape, so molecules with irregular outlines are measured as they are. Thin strands that a plain height threshold cannot separate from substrate roughness are picked up by their shape (narrow ridges). Substrate visible between strands is not counted in the area or volume.

Suited to: molecules with thin strands or irregular outlines, such as mRNA (an entangled clump with thin single strands), single-stranded DNA, intrinsically disordered proteins and aggregates.
Not suited to: images of round particles only (use Particle Analysis), or tracing the length of long fibres (use Filament Analysis).
The defaults were set on cropped 100 × 100 nm mRNA images (pixel size 1 nm). All lengths are given in nm, so the same values work for other pixel sizes and fields of view (see 4. Pixel size and field of view). For other kinds of molecule, start by adjusting the values described under Parameters.

1. Getting started

  1. Open an ASD file in pyNuD and show the frame you want to analyze.
  2. Open this plugin. The file name, frame number, pixel count, scan size and pixel size (nm/px) appear at the top left.
  3. Press Analyze Current Frame. The image with the detected outlines (cyan) appears on the right, and the measurements appear in the table below it.
  4. If an outline spreads beyond the molecule or a strand is cut short, adjust the values described under Parameters. The current frame is analyzed again as soon as you stop changing a value (Update on parameter change).
  5. To measure the whole movie, press Analyze All Frames. pyNuD returns to the original frame when it finishes.
  6. Save the results with Export CSV. Save Image saves the displayed image as PNG, PDF or SVG.

2. How the analysis works

  1. Background. A background fitted outside the molecules is subtracted, so the substrate is at 0 nm. Flat bands left at the image border by drift correction are ignored.
  2. Candidates. The lightly smoothed height and the response of a filter that enhances narrow ridges (ridge filter) are each divided by the background noise σ; the larger of the two is the evidence for a molecule.
  3. Two thresholds. Pixels above the high threshold form cores, and pixels above the low threshold are added as long as they connect to a core. Only regions containing a part whose smoothed height exceeds the Core threshold (6σ by default) are kept. Smoothing lowers the noise, so strands of ordinary height pass this test; what it drops is low, small noise blobs.
  4. Grouping. Nearby pieces are combined into one molecule.
  5. Outline (when Cut gaps between strands is checked). Substrate in the valleys between strands is removed from the outline; strand centre lines are kept.
  6. Islands. Of the pieces separated from the main body, only those that are close and long enough (broken strands) are kept.
  7. Measurement. Molecules touching the edge are excluded, then area, volume and the other values are calculated.

3. Parameters

Start with the defaults and change one value at a time while watching the outlines. All lengths are in nm; the pixel size comes from the scan size and pixel count in pyNuD.

Input

ParameterMeaning and when to change it
DataRaw height (recommended): the frame as stored in the file. The plugin corrects tilt and scan-line offsets itself.
Processed image: the image after pyNuD's filters or background correction. Use it when you want pyNuD's processing. If there is no processed image, the raw height is used.
BackgroundPolynomial (cropped image): a quadratic surface fitted outside the molecules is subtracted, then the median of each scan line is aligned. Use it for cropped single-molecule images and flat substrates. Volumes of large clumps are preserved.
Top-hat (raw wide field): structures wider than about twice the Top-hat radius are treated as background and removed. Use it for wide-field images with substrate undulation or large particles. Clumps wider than that come out with too small a volume.
Top-hat radiusUsed only with the Top-hat background. Make it larger than the radius of the clumps you measure. Too small cuts into the clumps; too large leaves substrate undulation. Default 8 nm.

Detection

ParameterMeaning and when to change it
Strand scale min / maxThe range of strand widths the ridge filter looks for, about the strand half-width (1–2 nm for strands that appear 2–4 nm wide). Raise the maximum when the tip makes strands look wider. Default 1.0 / 2.0 nm.
Low thresholdHow far strands are followed (in units of the background noise σ). Lower values reach further along strands but pick up more substrate noise. Default 2σ.
High thresholdHow strong a core must be. Lower values find lower molecules but keep more noise blobs. Default 4σ.
Core thresholdA molecule must contain a part whose smoothed height exceeds this (in σ). It removes faint noise blobs. Lower it when very low molecules (only a few times the background noise high) are not found; 0 switches the test off. Default 6σ.
Min areaObjects smaller than this are discarded as debris. Default 30 nm².

Molecule

ParameterMeaning and when to change it
TargetAll molecules (default): measures every molecule in the field.
Largest molecule: measures only the largest molecule; for cropped single-molecule images where small debris around it should not be counted.
Grouping gapPieces whose outlines are at most this far apart (straight-line distance between the nearest pixel centres) are treated as one molecule, also when they are linked through other pieces. Raise it when one molecule is split into several IDs; lower it when neighbouring molecules merge. Default 4 nm.
Detected outlines extend 1–2 nm beyond the molecule because of image blur, so pieces with a slightly wider visible gap are also grouped. The distance is measured the same way for All molecules and Largest molecule.
Cut gaps between strandsWhen checked (recommended), substrate seen between strands is removed from the area and volume. When unchecked, the detected region is used as is, and the area comes out larger.
Island gapPieces (islands) within this distance of the main body are candidates to keep; measured like the Grouping gap. Default 3 nm.
Min island lengthA candidate island is kept only if its skeleton (centre line) is at least this long. This keeps broken strands and drops short stubs. Default 12 nm.
Exclude molecules touching the edgeWhen checked (recommended), molecules cut by the image edge or the drift-correction border are not measured, because their size and volume are incomplete. The number excluded is shown in the summary. With Largest molecule, if the largest molecule touches the edge, the result is zero molecules.

4. Pixel size and field of view

  • Lengths are in nm. Filter sizes, distances and the minimum area are converted to pixels with the pixel size, so images with different pixel sizes or fields of view can be compared with the same settings.
  • Non-square pixels (x and y pixel sizes differing by more than 1 %) are resampled to square pixels of the smaller size before analysis. The summary says so, and the image and outlines are shown on the resampled pixels.
  • Suitable pixel size. 2 nm or less, so that the apparent strand width (about 2–4 nm) covers at least two pixels. At about 3 nm per pixel, strands become thinner than a pixel and the area comes out 20–30 % small (the volume is nearly preserved).
  • Drift-correction borders (bands of constant value at the image edge) are found and excluded automatically for any image size.
  • Processing time per frame is about 1 s for 400 × 400 px and about 2.5 s for 800 × 800 px (Apple M series). Analyze All Frames takes this time multiplied by the number of frames.

5. Reading the results

ColumnMeaning
IDMolecule number, matching the white number on the image.
Area (nm²)Number of pixels inside the outline × pixel area.
Volume (nm³)Sum of heights inside the outline (substrate = 0 nm) × pixel area.
Max height / Mean height (nm)Maximum and mean height inside the outline.
Skeleton length (nm)Length of the one-pixel-wide centre line (skeleton). Diagonal steps count as √2 pixels, so the value does not depend on direction. Short branches from a ragged outline and small holes inside clumps are removed before measuring.
For strands it is close to the true length (a few nm longer, because the faint ends are included). For molecules with a clump, the skeleton inside the clump changes with the pixel size, and so does the value; compare it only between images with the same pixel size.
RegionsNumber of separate pieces in the molecule. Values above 1 mean that broken strands were kept as islands.
X, Y (nm)Centre of the molecule, calculated at pixel centres; the origin is the lower-left corner of the image.

Background σ in the summary is the spread of the height outside the molecules (nm). The thresholds are multiples of this σ. If σ differs a lot between images, reconsider the background choice.

6. Troubleshooting

ProblemTry
No molecule is foundLower the High threshold and the Core threshold. Check whether the molecule touches the edge (compare with Exclude molecules touching the edge unchecked).
Strands are cut shortLower the Low threshold. Lower Min island length. Raise Strand scale max.
Substrate noise sticks to moleculesRaise the Low threshold. Raise Min area.
One molecule is split into severalRaise the Grouping gap.
Neighbouring molecules mergeLower the Grouping gap.
Large clumps have too small a volumeUse the Polynomial background, or raise the Top-hat radius.
Substrate undulation is detected as moleculesUse the Top-hat background.
A molecule is excluded at the edge together with a nearby pieceA piece touching the edge within the Grouping gap may be a strand leaving the field, so the whole molecule is excluded. Lower the Grouping gap only when the image shows that the piece is something else, such as debris.

7. CSV contents

Lines starting with “#” give the source path, the plugin version, every parameter used, the pixel size of the source data and the pixel size used for the analysis (after any resampling). Below them, each molecule has one row with frame, id, area_nm2, volume_nm3, max_height_nm, mean_height_nm, skeleton_length_nm, n_regions, x_nm and y_nm. Column names are in English in both languages.
